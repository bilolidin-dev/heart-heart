# heart-heart

Небольшая веб-анимация с сердцами, частицами и физикой на Matter.js.

## Запуск

Откройте `index.html` в современном браузере. Для загрузки библиотек Matter.js, PathSeg и poly-decomp требуется подключение к интернету.

## Технологии

- HTML
- CSS-анимации
- JavaScript
- [Matter.js](https://brm.io/matter-js/)

## Структура проекта

- `index.html` — разметка сцены и подключение библиотек
- `style.css` — оформление и анимация сердец
- `script.js` — физика и поведение частиц
